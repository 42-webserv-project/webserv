## Logger

* Discussed the current Logger implementation.
* The Logger is used for:

  * Error messages
  * Warning messages
  * Informational messages
  * General debug/print output
* Logging is exposed through easy-to-use macros that call the appropriate Logger functions.
* The exact guidelines for each log level are still to be defined and are currently based on common industry practices.
